เปิดไฟล์ใน Google Sheets > ไปที่เมนู ไฟล์ (File) > แชร์ (Share) > เผยแพร่ทางเว็บ (Publish to web) > เปลี่ยนรูปแบบเป็น Comma-separated values (.csv) แล้วคัดลอก URL

ขั้นตอนการนำ Dashboard ขึ้น GitHub Pages

ขั้นตอนที่ 1: บันทึกไฟล์นี้เป็น index.html

คัดลอกซอร์สโค้ดในหน้านี้ทั้งหมด แล้วเซฟเป็นไฟล์ชื่อ index.html บนเครื่องคอมพิวเตอร์ของคุณ

ขั้นตอนที่ 2: สร้าง Repository บน GitHub
  1. เข้าเว็บไซต์ GitHub.com แล้วเข้าสู่ระบบ
  2. กดปุ่ม New Repository ตั้งชื่อเช่น epi-dashboard
  3. เลือกประเภทเป็น Public จากนั้นกดปุ่ม Create repository
ขั้นตอนที่ 3: อัปโหลดไฟล์ index.html
  1. ในหน้า Repository คลิกที่ข้อความ uploading an existing file
  2. ลากไฟล์ index.html วางเพื่ออัปโหลด
  3. กดปุ่ม Commit changes
ขั้นตอนที่ 4: เปิดใช้งาน GitHub Pages
  1. ไปที่เมนู Settings ด้านบน > เมนูด้านซ้ายเลือก Pages
  2. หัวข้อ Build and deployment เลือก Branch เป็น main (หรือ master) และโฟลเดอร์ /(root)
  3. กดปุ่ม Save
  4. รอประมาณ 1-2 นาที คุณจะได้ URL เว็บไซต์สาธารณะสำหรับแชร์ให้ทีมงานเข้าดูได้ทันที!
